## 🚀 Projects

### ISLtoText | Indian Sign Language to Text
- Real-time webcam-based ISL recognition system for the speech and hearing-impaired community
- Built using MobileNetV2 transfer learning and MediaPipe hand landmark extraction
- Trained on a custom 14K+ image, 47-class dataset, achieving 92% validation accuracy
- Optimized inference pipeline running at 18–25 FPS, with gesture stabilization and cooldown logic for reliable continuous prediction
- Evaluated using precision, recall, and confusion matrix analysis
- Research paper submitted to NICEDT-2026

📄 https://drive.google.com/file/d/1wIRFR0pKLkOFd8Ja7oSwvqw3iMoiSCLl/view?usp=sharing · 💻 https://github.com/sumve/Indian-Sign-Language-To-Text

### Trendflix | Netflix Analytics & Recommendation Platform
- Interactive analytics dashboard aggregating IMDb, Rotten Tomatoes, and Metacritic data
- Recommendation ranking engine using weighted scoring and filtering logic
- Built with JavaScript and Chart.js for interactive visualizations and search-based filtering

🔗 https://sumve.github.io/Trendflix/#/ · 💻 https://github.com/sumve/Trendflix

### SunNotScreen | Sunscreen Photostability Tester
- Rule-based classification system analyzing cosmetic ingredient labels for UV photostability
- Flags photounstable ingredient pairs (e.g., Avobenzone + Octinoxate) using cosmetic-chemistry logic
- Deployed on Netlify as a lightweight, responsive tool for public usability
